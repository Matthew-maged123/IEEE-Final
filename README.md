# 🚀 يوزرسيف للطباعة والتخصيص في أسوان (Yuzersef Aswan)
## منصة طلب وتتبع خدمات الطباعة والهويات البصرية (Frontend-Only Prototype)
### 🏆 مشروع مسابقة Brand & Build × يوزرسيف (IEEE Aswan Student Branch)

تطبيق ويب متكامل للواجهة الأمامية مبني بأحدث تقنيات **React 19 + TypeScript + Vite + Tailwind CSS v4**. صُمم التطبيق بالكامل وفق منهجية **Mobile-First** (بدءاً من أصغر شاشة **375px** وتوسعاً للشاشات الأكبر) مع دعم كامل وتأصيلي للغة العربية والاتجاه من اليمين لليسار (**RTL**) والالتزام الدقيق بكافة متطلبات وثيقة التحكيم.

---

## 🌟 1. الميزة الفارقة الإلزامية: "مساعد جاهزية الطلب" (Request-Readiness Assistant)
*وفقاً لما ورد في وثيقة المسابقة (ص 1، 3، 11، 14):*
- **المشكلة:** البيانات والمواصفات الناقصة أو غير المتطابقة من العملاء تؤدي لتأخير قرارات المعمل وتراكم الرسائل.
- **الحل البرمجي المنفذ:** تم بناء لوحة فحص ذكية لحظية (Live Assistant Panel) تتابع مدخلات العميل وتمنع إرسال الطلب حتى تستوفى كافة الشروط:
  1. **فحص تطابق توزيع المقاسات (Size Breakdown):** عند طلب تيشرتات أو هوديز، يفحص النظام مجموع مقاسات (S + M + L + XL + XXL) مع الكمية الكلية. فإذا طلب العميل 10 قطع ووزع 7 فقط، يظهر التنبيه الفوري: `عدم تطابق: يتبقى توزيع 3 قطع` ويمنع الإرسال حتى تتطابق الأرقام!
  2. **فحص موضع الطباعة (Print Placement):** إلزامي للملابس والكابات (صدر، ظهر، جيب، كم، الجهتين).
  3. **فحص التصميم أو المساعدة (Artwork / Design Help):** التحقق من رفع ملفات التصميم أو تفعيل خيار "أحتاج مساعدة فنية من مصممي يوزرسيف".
  4. **حقول ديناميكية مخصصة:** إظهار موديل الهاتف لجرابات الموبايل، وأبعاد وقص الاستيكرات (Die-cut)، وإخفاء مقاسات الملابس عند اختيار منتجات أخرى.
  5. **تنبيه الإخلاء القانوني:** *"فحص الجاهزية الذكي لا يضمن مطابقة الألوان النهائية بنسبة 100% في خطوط الإنتاج"*.

## 🧵 3. خدمات «يوزرسيف» الفعلية بأسوان
تمت مطابقة الخدمات الستة لما هو معلن ومطلوب في الوثيقة:
1. **تيشرتات وهوديز وسويت شيرت مطبوعة** (قطن مصري، DTF، وتوزيع مقاسات).
2. **كابات مطبوعة ومطرزة** (بيسبول وسناب باك بتطريز بارز).
3. **استيكرات ولواصق مخصصة** (قص Die-cut، فينيل مقاوم للماء والشمس).
4. **مجّات وهدايا ترويجية** (مجّات سيراميك وسحرية، ثيرموسات حرارية).
5. **جرابات هواتف مخصصة** (طباعة UV ثلاثية الأبعاد لكافة الموديلات).
6. **تصاميم مخصصة ومساعدة فنية** (رسم فيكتور وتجهيز الشعارات للطباعة).

## 🧪 6. خطة اختبار العرض أمام الحكام (Pre-Presentation Script ص 14 & 15)
1. **تصفح الهوية والخدمات (10-20 ثانية):** زيارة الصفحة الرئيسية واستعراض أنيميشن الطباعة وألوان الهوية.
2. **اختيار عمل كمرجع (30 ثانية):** الدخول لمعرض الأعمال والنقر على *"استخدم كمرجع لطلبك"* لينقلك للمعالج.
3. **اختبار مساعد الجاهزية بخطأ متعمد (60 ثانية):**
   - اختيار 10 تيشرتات، وتوزيع 7 فقط في المقاسات -> يظهر تنبيه المساعد باللون الأحمر ويمنع الإرسال.
   - تعديل المقاسات لتصبح 10 -> يتحول الفحص للون الأخضر ويسمح بالمتابعة.
4. **إرسال الطلب واستلام الرمز (15 ثانية):** تأكيد الطلب واستلام الكود التسلسلي (مثال: `YZ-0005`).
5. **لوحة المسؤول (60 ثانية):** تسجيل الدخول بـ `admin/demo123`، فتح الطلب، كتابة توجيه الخطوة التالية (Next Step)، واعتماد الطلب أو بدء طباعته.
6. **متابعة العميل الحية (30 ثانية):** فتح صفحة التتبع وتحديثها لمشاهدة القرار الجديد ورسالة الواتساب الجاهزة.
