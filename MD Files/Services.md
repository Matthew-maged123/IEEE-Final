## 2. الغرض الوظيفي وسياق الأعمال (Business Purpose & User Journey)

تعتبر صفحة الخدمات صالة العرض المركزية للوكالة، حيث تستعرض بدقة وتفصيل جميع حلول الطباعة الرقمية والتطريز الكمبيوتري وتخصيص الهدايا ومستلزمات الهوية البصرية المتوفرة في معمل يوزرسيف بأسوان.

### الأهداف الرئيسية للصفحة:
1. **استعراض شامل ومنظم للكتالوج (Categorized Exploration):** تقسيم الخدمات إلى تصنيفات محددة بدقة لتسهيل وصول العميل إلى منتجه المطلوب في ثوانٍ معدودة.
2. **الشفافية في التسعير وفترات التنفيذ (Preliminary Transparency):** عرض التسعير التقريبي الأولي ومتوسط أيام التنفيذ المتوقعة لكل خدمة لتقليل الاستفسارات المتكررة.
3. **توضيح المواصفات الفنية والخامات (Material & Spec Highlights):** إبراز أبرز 3 مزايا وخامات لكل خدمة مباشرة من واجهة البطاقة.
4. **مساران للتحويل الفوري (Dual Conversion Pathways):**
   - مسار الاستكشاف العميق: زر *"التفاصيل الكاملة"* يقود إلى `/services/:id` لتشغيل استوديو المعاينة التفاعلي.
   - مسار الطلب المباشر: زر *"طلب فوري"* يقود إلى `/request?service=:id` مع ربط معالج الطلبات بالخدمة تلقائياً.

## 3. الهيكل المعماري وشجرة المكونات (Component Architecture)

```
Services (src/pages/Services.tsx)

 │    ├── Demo Badge ("خدمات الطباعة والتخصيص في أسوان - Demo Services")
 │    ├── Main Title ("خدمات الطباعة والتخصيص المعتمدة")
 │    └── Subtitle Description (شرح الخامات وتقنيات الطباعة)

 └── Section 3: Services Grid & Data Engine (شبكة عرض الخدمات)
      ├── Loading State Skeleton (6 بطاقات تحميل هيكلي بنبضات بصرية)
      └── Loaded Services Grid (بطاقات الخدمات المتجاوبة):
           ├── Card Header (أيقونة الفئة الديناميكية + شارة التميز)

                ├── Link -> /services/:id (التفاصيل الكاملة)
                └── Link -> /request?service=:id (طلب فوري)
```

## 4. حالة المكون وإدارة البيانات (State Management & Data Flow)

تعتمد الصفحة على ثلاثة متغيرات حالة تفاعلية في React:

```typescript
// قائمة الخدمات المسترجعة من الـ Mock API
const [services, setServices] = useState<Service[]>([]);

// الفئة النشطة الحالية للفلترة (الافتراضي: 'الكل')
const [activeCategory, setActiveCategory] = useState<string>('الكل');

// حالة التحميل لإظهار تأثير الـ Skeleton
const [loading, setLoading] = useState<boolean>(true);
```

### دورة حياة جلب البيانات (Lifecycle Hook):
```typescript
useEffect(() => {
  getServices().then((res) => {
    setServices(res);
    setLoading(false);
  });
}, []);
```
- عند تحميل المكون لأول مرة، يتم استدعاء دالة `getServices()` غير المتزامنة من `src/lib/mock-api.ts`.
- يتم تعيين البيانات في مصفوفة `services` وإلغاء حالة التحميل `loading=false`.

### آلية الفلترة السريعة (Instant Client-Side Filtering):
```typescript
const filteredServices =
  activeCategory === 'الكل'
    ? services
    : services.filter((s) => s.category === activeCategory);
```
تتم الفلترة محلياً في الذاكرة دون الحاجة لإعادة الاتصال بالخادم، مما يوفر تجربة تصفح فورية (Zero-Latency).

## 6. تفصيل محتوى بطاقة الخدمة الواحدة (Service Card Breakdown)

تتكون كل بطاقة خدمة من خمس طبقات وظيفية:
1. **الترويسة والأيقونة:** مربع بارز بنسبة ألوان هادئة `bg-[#065E5A]/10 text-[#065E5A]` يحمل أيقونة مخصصة لنوع الفئة، وإلى جانبه الشارة الترويجية مثل "الأكثر طلباً" أو "تسليم سريع" في حال وجودها.
2. **العنوان والوصف:** عنوان بارز عريض `font-bold text-xl text-slate-900` يليه وصف مختصر يركز على الفائدة المباشرة للعميل.
3. **قائمة المواصفات المقتضبة:** يتم استقطاع أول ثلاث مواصفات (`features.slice(0, 3)`) وعرضها بقوائم نقطية مع علامات تحقق خضراء `CheckCircle2` لإعطاء العميل فكرة سريعة عن الجودة.
4. **شريط التسعير ومدة الإنجاز:**
   - الجانب الأيمن: "التسعير التقريبي" يعرض `startingPrice` (مثل: "يبدأ من 220 ج.م").
   - الجانب الأيسر: "متوسط التنفيذ" يعرض `estimatedDays` مصحوبة بأيقونة ساعة زمنية (مثل: "2 - 4 أيام عمل").
5. **منطقة أزرار الإجراء:** شبكة ثنائية متناسقة `grid grid-cols-2 gap-3` تمنح العميل حرية الاختيار بين قراءة المواصفات الكاملة أو التوجه فوراً لتقديم طلبه.

## 7. التصميم البصري واستجابة الشاشات (UI/UX Styling)

- **أزرار الفلترة النشطة (Active Pills):**
  - الحالة المحددة: `bg-[#E3A92F] text-[#073B35] border-2 border-[#073B35] shadow-[3px_3px_0px_#073B35]` (أسلوب نيومورفيزيم الرترو الملموس).
  - الحالة غير المحددة: `bg-white text-[#073B35] border-2 border-[#d9d2c3] hover:border-[#073B35]`.
- **شريط التمرير الأفقي للفئات:** استخدام `overflow-x-auto scrollbar-none` يتيح للمستخدمين على شاشات الهواتف التمرير الأفقي السلس بالأصابع دون ظهور شريط تمرير قبيح.
- **تأثيرات التحميل الهيكلي (Skeleton Loading):** عند بدء التحميل تظهر 6 بطاقات متحركة بنبض رمادي خفيف `animate-pulse bg-slate-200/60` بنفس أبعاد الكروت لتجنب حدوث أي قفزة بصرية (Layout Shift - CLS).

## 8. معالجة الحالات الخاصة والحواف (Edge Cases & Validation)

1. **انعدام نتائج التصفية:** في حال اختيار فئة فارغة، يتم إظهار مصفوفة فارغة بنعومة دون حدوث أي خطأ برمجي (Null Pointer Exception).
2. **اختلاف أطوال العناوين:** تم تثبيت الهيكل العام للبطاقة عبر استخدام `flex flex-col justify-between` لضمان محاذاة أزرار الإجراء في أسفل جميع الكروت على نفس الخط الأفقي بغض النظر عن طول النصوص.
3. **التجاوب مع الشاشات اللمسية:** تكبير مساحات النقر في أزرار الفلترة لسهولة الضغط بالإبهام على الهواتف.
